# **Diseño**

- **Casos de uso**:![Casos de uso](/doc/img/diagramaCasosDeUso.png)
- **Deseño da interface de usuarios** :
    - **Login**:![Login](/doc/img/mockup/1.png)
    - **Inscribirse**:Permitirá registrar un nuevo uusario, se accerá mediante el
     botón de registrate del login.
    ![Inscribirse](/doc/img/mockup/2.png)
    - **Home**:Permitirá seleccionar el grupo muscular que desees para posteriormente seleccionar el ejercicio.
    ![home](/doc/img/mockup/3.png)
    - **Ejercicios**:Una vez seleccionado el grupo muscular anteriormente, aparecerán los ejercicios correspondientes a este.
    ![Ejercicios](/doc/img/mockup/4.png)
    - **Añadir Ejercicio**:Una vez seleccionado el ejercicio aquí podrás añadir la información acerca de ese ejercicio.
    ![AñadirEjercicio](/doc/img/mockup/5.png)
    - **Desplegable**:Menú desplegable correspondiente a la rueda de configuración.
    ![Desplegable](/doc/img/mockup/6.png)
    - **Administración de usuarios**:Permitirá gestionar los usuarios. Se accederá a esta ventana mediante la rueda de configuración, clicando en: añadir, borrar o actualizar. Esta ventana permitirá añadir nuevos usuarios, actualizar los usuarios ya existentes y borrar usuarios que dejen de usar la aplicación.
    ![AdministraciónUsuarios](/doc/img/mockup/7.png)
    - **Administración**:Permitirá añadir nuevas máquinas y ejercicios. Se accederá a esta ventana mediante la rueda de configuración, haciendo clic en 'añadir ejercicio' o 'máquina'.
    ![Administración](/doc/img/mockup/8.png)
    - **Rutina actual**:Visulización de la rutina actual, se accederá aquí mediante el bottón de rutina actual.
    ![RutinaActual](/doc/img/mockup/9.png)
    - **Historial entrenamientos**:Visualización del historial de entrenamientos. Se podrá hacer clic sobre una de las fechas en las que se realizó un entrenamiento, accediendo mediante el botón 'todas las rutinas'.
    ![HistorialEntrenamientos](/doc/img/mockup/10.png)
    - **Visualizar entrenamiento del historial**:Posteriormente a haber clicado sobre una fecha del historial, se accederá a esta ventana donde podrás ver el entrenamiento con detalle.
    ![VisualizarEntrenamientoHistorial](/doc/img/mockup/11.png)
